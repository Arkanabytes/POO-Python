## 📖 Conceptos Clave

### Clase
```python
class MiClase:
    def __init__(self, parametro):
        self.atributo = parametro
    
    def metodo(self):
        return f"Valor: {self.atributo}"
```

### Objeto
```python
mi_objeto = MiClase("valor")
print(mi_objeto.metodo())
```
